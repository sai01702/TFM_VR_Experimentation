================================================================================
WHAT WAS THE PROBLEM?
================================================================================

The ExperimenterClientScene was missing a NetworkManager GameObject!

The observer scripts (ObserverConnectionUI, ObserverSessionUI, ObserverCameraDisplay)
rely on NetworkManager.Singleton to connect to the host, but the scene didn't
have a NetworkManager at all.

    ├── Protocol Type: UnityTransport (LAN)

================================================================================
NETWORK CONFIGURATION
================================================================================

The NetworkManager is configured for LAN connection by default:

UnityTransport Settings:
- Protocol: UnityTransport (not Relay)
- Address: 127.0.0.1 (localhost)
- Port: 7777
- Server Listen Address: (empty - auto)
- Max Connect Attempts: 60
- Connect Timeout: 1000ms
- Disconnect Timeout: 30000ms
- Heartbeat: 500ms

This means:
✓ Works on same PC (localhost)
✓ Works on LAN (local network)
✓ Works with direct IP connection
✗ Doesn't work over internet without port forwarding
✓ Can switch to Unity Relay if needed

================================================================================
SWITCHING TO RELAY (IF NEEDED)
================================================================================

If you want to use Unity Relay for internet connection:

1. In ObserverConnectionUI script, there's a useRelayToggle field
2. You can add a Toggle UI element for this
3. When toggled ON:
   - Connection uses Unity Relay instead of direct IP
   - User enters Join Code instead of IP:Port
   - Works over internet without port forwarding

For now, LAN mode is enabled (simpler setup).

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Still getting "NetworkManager not found"
Solution:
- Open ExperimenterClientScene in Unity
- Check Hierarchy for "NetworkManager" GameObject
- If missing, manually create it:
  1. GameObject > Create Empty
  2. Name it "NetworkManager"
  3. Add Component > NetworkManager
  4. Add Component > Unity Transport

Issue: "Connect" button does nothing
Solution:
- Check Console for error messages
- Verify NetworkManager has UnityTransport component
- Check ObserverConnectionUI has all references assigned

Issue: "Connecting..." but never connects
Solution:
- Verify host is actually running and hosting
- Check firewall settings (allow Unity on port 7777)
- Try "127.0.0.1:7777" for same-PC test
- Check both PCs are on same network (for LAN)

Issue: Connected but no video stream
Solution:
- Verify PlayerCameraStreamer is on player rig in host scene
- Check player has a Camera component
- Look for errors in host Console

Issue: Connected but session info shows "N/A"
Solution:
- Verify NetworkSessionManager is spawned on host
- Check host has set participant ID
- Verify ObserverSessionUI references are correct
